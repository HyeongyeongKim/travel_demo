# Demo 날짜별 작업 기록

작성 기준일: 2026-11-12

대화, 기획 문서의 갱신일, 현재 파일을 기준으로 정리했습니다. 과거 작업이 개별 커밋으로 남아 있지 않아 세부 작업일을 모두 확정할 수는 없습니다. 날짜가 불명확한 변경은 별도로 표시하며, 이번 업로드의 커밋 날짜를 과거 날짜로 바꾸지 않습니다.

## 2026-11-10 · 기획 정리와 개발 기반

기획 문서의 갱신일과 개발 환경 파일 기록을 기준으로 정리했습니다.

- workflow와 개발계획 내용을 `여행플랜_기획.md`로 통합하고 디자인 PDF를 참고 원본으로 유지했습니다.
- Demo라는 이름으로 모바일·PC 웹을 먼저 만들기로 했습니다.
- React + JavaScript + Vite + React Router와 직접 작성한 CSS를 선택했습니다.
- 서버는 Node.js + Fastify, DB는 MySQL, DB 접근은 mysql2 + SQL, 로그인 유지는 서버 세션 + 쿠키로 정했습니다. DB와 인증은 아직 구현 전입니다.
- `web/`, `server/` 개발 환경과 서버의 `/health` 경로를 구성했습니다.
- 모든 여행 멤버의 공동 편집, 마지막 저장 우선, 삭제된 항목 안내, 여행 삭제 전까지 유지되는 초대 링크 등 협업 규칙을 문서화했습니다.
- 여행 나가기, 마지막 멤버가 나가면 여행 전체 삭제, 별도 여행 삭제 기능의 방향을 정했습니다.

## 2026-11-10~12 · 디자인 방향 및 인증 화면 초안

이 구간의 개별 변경 날짜는 확인되지 않았습니다.

- 흰색과 선명한 파란색 중심, 이미지 최소화, 모던하고 심플한 디자인 방향을 정했습니다.
- 디자인은 탐색용 초안으로 두고 기능 구현 후 다듬기로 했습니다.
- 디자인 PDF의 로그인 레이아웃을 참고해 로그인 화면을 구성했습니다.
- 인트로에 로고 자리와 Demo 이름, 앱 시작하기 버튼을 배치했습니다.
- 로그인·회원가입 화면과 입력 안내를 만들었습니다.
- 소셜 로그인 버튼은 화면에만 있으며 실제 로그인은 연결되지 않았습니다.

## 2026-11-12 · 핵심 화면과 이동 흐름

### 홈

- 인사말, 프로필, 다가오는 여행, 내 여행, 친구들의 새 글, 하단 메뉴를 구성했습니다.
- 다가오는 여행 카드의 일정·준비물 진행률을 사용자 요청에 따라 제거했습니다. 여행 내부의 일정·준비물 기능을 제거한 것은 아닙니다.
- 사용자와 여행 정보는 예시 데이터이며, 여행 만들기·참여하기 외 홈 버튼은 아직 연결되지 않았습니다.

### 새 여행 만들기

- 홈에서 `/trips/new`로 이동하도록 연결했습니다.
- 여행 이름, 나라·도시, 시작일·종료일 입력란을 만들었습니다.
- 필수 항목 입력 시 버튼 활성화, 여행 기간 표시, 종료일 오류 안내를 추가했습니다.
- 나라·도시는 현재 직접 입력하며 장소 검색 서비스는 연결하지 않았습니다.
- 사용자 요청에 따라 함께 가는 친구 입력란·검색 버튼·안내 문구를 제거했습니다. 기획 문서의 생성 시 친구 검색 설명보다 이 최신 화면 결정이 우선합니다.
- 실제 여행 저장은 연결 전이며, 제출 시 안내하고 입력을 유지합니다.

### 여행 참여하기

- 홈에서 `/trips/join`으로 이동하도록 연결했습니다.
- 초대 링크 입력, 빈 입력 시 버튼 비활성화, 기본 URL 형식 오류 안내를 추가했습니다.
- 삭제된 여행의 링크를 사용할 수 없다는 안내를 배치했습니다.
- 실제 초대 토큰 확인, 여행 정보 조회, 삭제 여부 확인, 멤버 등록은 서버 연결 후 구현합니다. URL 형식 통과가 유효한 초대임을 의미하지는 않습니다.

### 작업 규칙과 확인

- 작업 후 다음에 할 일을 안내하는 규칙을 `AGENTS.md`에 기록했습니다.
- 화면 작업에서 웹 프로덕션 빌드가 통과했습니다.
- 실제 브라우저 시각 검수와 서버 연동 검증은 아직 하지 않았습니다.
- 이번 업로드를 위해 README와 날짜별 작업 기록을 작성하고 임시 파일·환경 설정의 Git 제외 규칙을 보완했습니다.
